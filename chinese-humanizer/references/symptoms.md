# 症状目录

四层结构，每条给「触发条件 / 保护项 / 改写动作 / 证据」。证据分三档：

- 【实测】有中文语料统计支持，数字见 `evidence.md`
- 【观察】编辑经验，方向可信但没有语料校准
- 【跨语言】源自英文语料的模式，中文侧按同构现象处理，不能照搬形态

用的时候先看触发条件，再看保护项。命中多个相邻条目只处理一次，别逐条套用。

## 1. 篇章结构层

### 1.1 开头铺垫与任务复述 【观察】
- 触发：正文开始前先交代背景、复述需求、宣布「下面分三个方面」。
- 保护：演讲导读、长文导航、正式摘要的必要交代。
- 动作：直接从事实、问题或结论开始。删掉开场后正文若仍然成立，就是废话。
- 例：「在当今快速发展的时代背景下」→ 删，直接写事。

### 1.2 段落过齐与一段一模板 【实测·间接】
- 触发：每段同样长、同一种开头、同一种收束，全篇「观点—解释—升华」循环。
- 保护：条款、步骤、需要横向比较的文档。
- 动作：按职责合并或拆分：事实归事实，原因归原因，限制条件单独说。
- 数据：AI 篇章段落数是人类的 2.5 倍左右，平均段落长度更短（92.747 比 123.907）。

### 1.3 篇幅膨胀与同义复述 【实测】
- 触发：相邻句换词说同一件事；整段删掉只减少字数，不减少信息。
- 保护：必要定义、教学分解、给不同读者的复述。
- 动作：合并重复判断，让事实和动作承担主干。
- 数据：相邻句词语重复性 0.545（人类）比 0.875（AI）。

### 1.4 收尾复述与统一升华 【观察】
- 触发：结尾把前文再说一遍，再展望、号召、拔高；每段都用「这说明」封口。
- 保护：正式摘要、结论章节、用户明确要的行动项。
- 动作：停在最后一个有信息的事实、判断或动作上。

### 1.5 任意分层与大纲模板 【观察】
- 触发：硬凑三点，「首先 / 其次 / 最后」拆散本来连贯的叙述，每点写成「标签：解释」。
- 保护：操作步骤、参数表、责任分工、真实分类。
- 动作：按读者的任务重排成自然段或真正的层级。

### 1.6 笼统前景与假平衡 【观察】
- 触发：「尽管面临挑战，前景依然可期」「既要 X 又要 Y」，没有真实冲突或取舍。
- 保护：原文确有权衡、计划或作者态度。
- 动作：写清条件和决策；没有信息的乐观结尾删掉。

## 2. 句法与语序层

### 2.1 弱动词与名词化 【实测·间接／余光中】
- 触发：「进行 / 作出 / 实现 / 推动 / 构建 / 开展 + 抽象名词」「性 / 化 / 度」堆叠。
- 保护：学术、公文、法律、技术里的稳定术语。不要机械拆术语。
- 动作：恢复「谁做了什么」。进行研究→研究，作出贡献→贡献很大，具有较强的可读性→很好看。

### 2.2 「的」字连珠与长定语 【观察·余光中】
- 触发：一句里三个以上「的」，或者多层定语压得主干找不着。
- 保护：消歧需要的专名、固定术语。
- 动作：拆成短句，部分定语改成独立说明。「弯弯的杨柳的稀疏的倩影」→「弯弯的杨柳投下稀疏的倩影」。

### 2.3 前饰过载（缺后饰） 【观察·余光中】
- 触发：一身定语全堆在名词前面，句子长且生硬。
- 保护：短定语不必动。
- 动作：改成后饰：「我见到一个长得像你兄弟的男人」→「我见到一个男人，长得像你兄弟」。

### 2.4 抽象名词当主语 【观察·余光中】
- 触发：拿一个名词做主词，而不是拿一件事做主词。
- 动作：还原成人或短句做主词。「他的收入的减少改变了他的生活方式」→「他收入减少，生活方式跟着变了」。

### 2.5 被动句滥用 【观察·余光中】
- 触发：连续「被」字句，施动者被藏起来；或者中文本来不用被动的场合硬套。
- 保护：受事或责任确实需要明确时的被动。
- 动作：改主动，或换用「受 / 遭 / 挨 / 经人 / 为世所重」这类说法。「我不会被你这句话吓倒」→「你这句话吓不倒我」。

### 2.6 主干后置 【观察】
- 触发：「在…背景下 / 基于… / 通过…的方式」叠两三层，谓语迟迟不出现。
- 保护：法律、公文、技术定义里承担适用范围的前置条件。
- 动作：先给主干，再放条件与范围。

### 2.7 介词结构直译 【观察·余光中】
- 触发：「在…方面」「通过…的方式」「对于…而言」「关于…」「由于…使得」。
- 动作：删或简化。有「由于」就不必再有「所以」；「由于好奇心的驱使」→「出于好奇」。
- 例：「今天讨论有关台湾交通的问题」→「今天讨论台湾交通」。

### 2.8 连接词空转 【观察】
- 触发：段段「此外 / 与此同时 / 值得注意的是 / 因此」，句间并没有真实的因果、转折或补充。
- 保护：真实的演绎步骤、实验推导、必要路标。
- 动作：删掉连接词看句子是否成立；成立就删。
- 注意：中文并列本来常常不用连接词（夫妻、你我、东南西北），但这不等于中文要少用到反直觉的程度：数据上「人类连词更多」和「AI 连词更多」两种口径互相冲突，见 `evidence.md`。

### 2.9 句长句式匀速 【实测】
- 触发：连着五六句长度接近、结构相同、停顿位置一致。
- 保护：条款、步骤、有意排比。
- 动作：按信息重心拆长句、合并碎句，让长短交替。
- 数据：句长标准差人类 9.248 / AI 6.729（词例口径），四个口径方向一致。

### 2.10 并列短语堆叠 【实测】
- 触发：一句里塞三四个并列成分，尤其近义形容词连排。
- 保护：真实完整清单、法定要件、步骤。
- 动作：能合并的合并，功能或身份评价另起一句。
- 数据：句均并列短语数 0.251（人类）比 0.729（AI），是本批论文里最突出的句法特征。

### 2.11 无主句与虚假施动 【跨语言】
- 触发：「数据告诉我们」「市场会奖励」「结果显示」这类把责任推给抽象物的句子。
- 保护：方法部分必要的被动或无主句。
- 动作：能点名就点名：谁做的、谁说的、谁受影响。

### 2.12 代词与主语赘余 【观察】
- 触发：机械重复「它 / 该 / 其 / 我们」，一句一个主语。
- 保护：不省主语会造成歧义时。
- 动作：语境清楚就省。

### 2.13 中英混排堆叠 【跨语言】
- 触发：「AI-native、全链路、高可用」式复合词连堆，且没有解释。
- 保护：产品名、协议名、代码、文件名、稳定术语。
- 动作：保留必要术语，首次出现时说清含义，其余删掉。

## 3. 词汇层

### 3.1 一级黑话 【观察】
- 触发：赋能、深耕、聚焦、助力、打造、引领、闭环、抓手、全方位、多维度、一站式、底层逻辑、顶层设计、降本增效。密集出现即处理。
- 保护：确实有明确指代对象、且是行业固定用法时。
- 动作：问「这个词具体指什么」，用答案替换。详见 `vocabulary.md`。

### 3.2 二级套话 【观察】
- 触发：值得注意的是、值得一提的是、综上所述、由此可见、不难发现、毫无疑问、不可否认、与此同时。一段里三个以上就该动手。
- 动作：多数直接删，不找替代词。

### 3.3 伪深度词 【观察】
- 触发：底层逻辑、认知升级、思维模型、第一性原理、范式转移、颗粒度、飞轮效应、势能。
- 动作：换成直白说法。底层逻辑→根本原因，颗粒度→细节程度。

### 3.4 宣传腔与意义拔高 【观察】
- 触发：蓬勃发展、如火如荼、令人振奋；具有里程碑式的意义、为…注入了新的活力、树立了新的标杆。
- 保护：作者本人明确作出的评价要保留，只改承载方式。
- 动作：事实先行，评价另放；纯空洞升华删掉。

### 3.5 模糊归因与假共识 【观察】
- 触发：「业内人士认为」「研究表明」「普遍认为」，没有来源，或范围超出原文。
- 保护：真实来源、完整调查范围、必要概括。
- 动作：具体化来源；不能具体化就收窄范围或标「待核对」。绝不代填。

### 3.6 搭配漂移 【观察】
- 触发：动作词脱离自然对象：「接住观点」「击穿思考」「托住情绪」「打通链路」「拉齐认知」。
- 保护：真实动作、行业惯用语、人物声口、品牌语言。
- 动作：换成普通动词或直接写结果。

### 3.7 限定词串联 【观察】
- 触发：「可能、或许、通常、相对、一定程度上」连续叠加，表达同一层不确定。
- 保护：证据等级、适用范围、风险披露。
- 动作：只留最准确的一个限定，删掉重复的安全垫。不能把不确定清洗成确定。

### 3.8 伪术语 【观察·余光中】
- 触发：把形容词变名词再套上去：「具有很高的知名度」「可读性颇高」「颇具前瞻性」「太专业性的字眼」。
- 动作：换回形容词。很有名，很好看，更有远见，太专门。

### 3.9 实现细节盖过用户感受 【观察·用户反馈】
- 触发：写的是算法名、参数、迭代次数、内部机制。读者用得上的信息被埋在一串规格里。
- 保护：排错指南和技术文档里，参数就是读者要的东西，不算症状。这一条只针对面向使用者的介绍、推荐、说明。
- 动作：换算成读者能感知的结果。加密功能写「端到端加密，云端只有密文，主密码丢了找不回」，不写「PBKDF2-HMAC-SHA256 60 万次迭代加 AES-256-GCM」。同理，「数据走本地内存中转，不落本地磁盘」改成「两台远端服务器之间能直传，不用先下载到本地」。

## 4. 修辞与表现形式层

### 4.1 对称骨架与否定排比 【跨语言】
- 触发：「不是 X，而是 Y」「不仅 X，更 Y」「看似 X，本质 Y」「从 X 到 Y 再到 Z」。字面连词删掉但保留「先压低一项再抬高另一项」的关系，仍算残留。
- 保护：真实引语、固定定义、事实纠错、范围排除。
- 动作：冻结两端含义，改成事实主干、独立句或因果句。

### 4.2 三连与机械排比 【实测·间接】
- 触发：三个近义形容词、动词或身份排在一起，末项还往上抬。
- 保护：真实完整清单、步骤、法定要件、有意排比。三个独立故障、三个独立例子都要留着。
- 动作：能落在同一动作层的合并；身份评价另起一句。仅删掉「既 / 也 / 更」而把三项留在原句，不算改写。

### 4.3 段尾金句与戏剧化碎片 【跨语言】
- 触发：连续短句制造停顿，段尾来一句可以印在海报上的话。
- 保护：真正需要强调的单个短句。
- 动作：并回完整句子，写清具体变化。

### 4.4 破折号与冒号承担句法 【观察】
- 触发：破折号成串，每次都在「揭示」什么；分号、冒号替句子结构干活。
- 保护：真正的停顿、对话中断、并列层级；中文破折号是规范标点，不归零。
- 动作：先重写句法，再挑标点。只换标点不改结构等于没改。

### 4.5 排版装饰 【跨语言】
- 触发：每条都加粗加冒号、emoji 当标点、每个小节加分隔线。
- 保护：目标格式本身就是 Markdown；步骤、参数、数据对照需要结构时。
- 动作：只留承担功能的格式。

### 4.6 客服与协作残留 【跨语言】
- 触发：「希望以上信息对您有所帮助」「以下是关于…的介绍」「需要我展开吗」「当然可以」「非常好的问题」。
- 动作：删。正文里不该有对话痕迹。

### 4.7 知识截止声明与占位符 【跨语言】
- 触发：「截至我最后一次更新」「资料有限」「[姓名]」「XX」「待补链接」。
- 动作：能补的引事实；不能补的明说未找到，或保留占位并请作者补。绝不代填。

### 4.8 伪口语钩子 【观察】
- 触发：「说实话？」「讲真」「问题来了」「重点来了」单独成句当钩子。
- 保护：作者真实的语言习惯；句中正常使用的「说实话」。
- 动作：删钩子，直接写观点。

### 4.9 空评价收尾 【观察·用户反馈】
- 触发：「挺不错的」「体验很好」这类没有信息量的判断；把否定或评价切成短尾巴（「…这里没有」「…也不是不行」）。
- 动作：写具体：哪里好、比什么好、好在多少。切碎的尾巴并回完整句。

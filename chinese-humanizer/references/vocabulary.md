# 中文 AI 高频词表

词表是线索，不是禁令。**单个词出现一次通常不算问题**，成簇出现、脱离对象、让句子空转才处理。术语、品牌名、行业固定说法、引语里的词一律不动。

处理顺序：先问「这个词具体指什么」，再用答案替换。答不出来，说明它本来就没承载信息，删掉即可。

## 一级：密集出现即处理

这些词在 AI 中文里的密度远高于人类写作。同一个自然段里出现两个以上，就该动手。

| 词 | 替换方向 |
| --- | --- |
| 赋能 | 帮、支持、让…用上 |
| 深耕 | 做了很久、专注于 |
| 聚焦 | 关注、盯着、主要做 |
| 助力 | 帮、推动 |
| 打造 | 做、建、搞 |
| 引领 | 带头、领先 |
| 闭环 | 从头到尾、形成循环 |
| 抓手 | 切入点、办法、工具 |
| 全方位 / 多维度 | 各方面、（直接说哪几个方面） |
| 一站式 | 什么都有、全包 |
| 高质量 / 沉浸式 | 用数据说明质量或体验 |
| 底层逻辑 | 根本原因、说白了 |
| 顶层设计 | 整体规划、大方向 |
| 降本增效 / 提质增效 | 省钱、提效率、做得更好更快 |
| 数智化 | 数字化、用上了 AI |
| 新质生产力 | 说清具体是什么技术或产能 |

## 二级：一段里三个以上就处理

多数情况直接删，不要找替代词。

值得注意的是 · 值得一提的是 · 综上所述 · 由此可见 · 不难发现 · 毫无疑问 · 不可否认 · 不言而喻 · 众所周知 · 与此同时 · 事实上 · 总的来说 · 此外 · 另外

## 伪深度词

让内容看着有深度，实际没有内容。

底层逻辑→根本原因 · 认知升级→学到了新东西 · 思维模型→想法、方法 · 元认知→反思 · 第一性原理→从头想 · 范式转移→大变化 · 颗粒度→细节程度 · 飞轮效应→越转越快 · 杠杆→省力的办法 · 势能→优势、积累

## 宣传腔

亮眼 · 瞩目 · 欣欣向荣 · 蓬勃发展 · 硕果累累 · 令人振奋 · 可圈可点 · 有目共睹 · 蒸蒸日上 · 日新月异 · 突飞猛进 · 如火如荼 · 方兴未艾 · 势不可挡

用可验证的描述替换夸张形容。「业务蓬勃发展」→ 写出具体数字或变化。

## 意义拔高短语

具有里程碑式的意义 · 标志着…的新篇章 · 开创了…的先河 · 翻开了…的新一页 · 具有划时代的意义 · 为…注入了新的活力 · 为…提供了有力支撑 · 为…奠定了坚实基础 · 树立了…的新标杆

## 万能开头

随着…的不断发展 · 在当今…的时代 · 在…的背景下 · 作为…的重要组成部分 · 从…的角度来看 · 近年来（单独用正常，成簇可疑）

## 万能收尾

让我们拭目以待 · 未来可期 · 前景广阔 · 大有可为 · 充满无限可能 · 我们有理由相信 · 相信在未来 · 站在新的起点上 · 机遇与挑战并存

## 客服与协作残留

以下是关于…的介绍 · 针对您的问题 · 根据您的需求 · 希望以上信息对您有所帮助 · 如有疑问请随时咨询 · 非常感谢您的提问 · 以上供参考 · 当然可以 · 需要我展开吗

## 过度谦虚

仅供参考 · 以上只是个人浅见 · 不当之处敬请指正 · 一家之言，仅作抛砖引玉 · 水平有限

## 学术与报告专属

论断强于证据：证明了 · 证实了 · 彻底解决 · 充分揭示 · 必然导致 · 显著提升（无检验支持时）
新颖性注水：填补国内外空白 · 开创全新范式 · 达到国际领先水平 · 国内外尚无研究
空泛规模：大量实验 · 广泛数据集 · 全面系统地 · 多种场景

改法：降调或者补证据。「证明了 X」→「结果表明 X」或「与 X 相关」。

## 格言公式

「X 是 Y 的语言」「数据是新的货币」「效率会成为陷阱」「X 不是工具，而是一面镜子」。
这类句子看着像金句，实际上把普通判断包装成箴言。改成具体论点。

## 白名单：不要动

- 术语与技术名词：API、SDK、CLI、token、KV cache、CI、embedding 等，及项目自己的术语体系
- 品牌名、产品名、协议名、文件名、路径、代码标识符
- 法律与公文固定表达：特此说明、请予审示、现将…报告如下
- 引号内的引语
- 行业里确实有明确指代的说法（某个团队真的在用「闭环」描述他们的流程，就不是痕迹）

## 一句话原则

不按词表机械替换。同一个词在不同体裁里的判断不同：公文里正常，博客里可疑；有明确指代时正常，空转时可疑。

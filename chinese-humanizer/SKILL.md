# 中文表述拟人化

把简体中文里「像 AI 写的」那部分改掉：套话、名词化、欧化句式、模板化的节奏。目标是让文字像具体的人在讲一件具体的事，同时一个事实都不丢。

## 中文这种腔调从哪来

三条来源，下药要对准来源：

1. **模型回归均值。** 模型挑最可能的下一句，具体的、罕见的、带个人信息的部分被换成笼统说法。写出来的东西没有错，只是没有信息。
2. **RLHF 训练出的讨好写法。** 面面俱到的平衡、每段一个收尾、开头先铺垫重要性、「不仅…更是…」，都是被奖励过的形状。
3. **中文语料偏公文与译本。** 官方文书、新闻通稿占比高，模型学到一整套「该举措」「赋能」「闭环」；再叠上英文思维的直译：骨架是英文的，动词选择也是英文的（「展示了」＝ demonstrates），字却都是中文。

所以「像 AI」不是某个词的问题，是密度和形状的问题。单个词不算证据，成簇出现、让句子空转才算。

## 三条判断尺子

要不要改拿不准时，问这三句：

1. 删掉这句，信息少了吗？没少就是空话。
2. 谁做了什么，能不能一眼找到？找不到就是主干被埋。
3. 这句话有几个读法？能读出第二种意思就拆开写。

## 强度分级：什么时候动手

- **一见即改**：套话收尾（「综上所述」「让我们拭目以待」）、意义拔高（「具有里程碑式的意义」）、客服残留（「希望以上信息对您有所帮助」）、空转连接词连用、三项并列末项拔高、段尾金句式短句。
- **成簇才改**：一级黑话、二级套话、破折号、被动句、四字格。同类在一段里出现三个以上，或者整段都长成这个形状，才处理。
- **别动**：术语、引号里的引语、公文和法律文本的固定表述、代码与路径、品牌 slogan、作者自己的声口。清单见 references/boundaries.md。

## 工作流

1. **读全文，先列清单，不改稿。** 逐段记下命中的症状，写清「段落首句 + 症状名」。
2. **按清单改，一次改一类。** 改完一节回头念一遍，别把十种毛病揉进同一个句子。
3. **不许新增事实。** 数字、人名、经历、例子一律不补，缺细节就问，或者在末尾列「需要你确认」。
4. **交付前跑自查表**，每一条都能打勾才算完。
5. **文件模式只改正文散文。** 代码块、行内代码、命令、路径、YAML、链接目标都不动。

## 改写动作库（按命中率排序）

1. **弱动词复原。**「进行 / 作出 / 实现 / 推动 + 抽象名词」换回原本的动词：进行研究→研究，作出重大贡献→贡献很大。
2. **「的」字减负。** 一句里三个以上「的」就拆句；「夜色的来袭」→「夜色来袭」，「白色的鸭」→「白鸭」。
3. **抽象名词当主语改成人做主语。**「他的收入的减少改变了他的生活方式」→「他收入减少，生活方式也跟着变了」。
4. **删连接词。** 段首「此外 / 与此同时 / 值得注意的是」删掉，句子照样成立。
5. **拆并列。** 句均并列短语数 AI 是人类的近三倍（0.729 比 0.251），三项并列降到两项，或者拆成两句。
6. **减长词、补短词。** 人类单音节词占比 0.483，AI 0.379。「进行优化」→「改」，「予以考虑」→「想想」，「具有很高的知名度」→「很有名」。
7. **句长错落。** 人类句长标准差是 AI 的 1.3 到 1.5 倍。短句之后接一句要读两遍的长句，比一路匀速强。
8. **相邻句不重复同一个实词。** 相邻句词语重复性 0.545 比 0.875，是判别力最强的一组特征。同一段里同一个词出现三次，第二次就该换说法或直接省掉。
9. **段落别切太碎。** AI 的篇章段落数是人类的两倍多，平均段落更短。把一句一段合回自然段。
10. **落到具体。** 抽象形容词换数字、场景、动作，前提是事实支持。事实不支持就删掉那句。
11. **删收尾的升华。** 最后一段在复述前文或展望未来时，整段删。
12. **断句式收尾合并成完整句。** 把否定或评价切成一个短尾巴（「…笨重感这里没有」）是英文断句习惯，中文写成完整句。

## 交付前的自查表

- [ ] 有没有句子删掉后信息不变？
- [ ] 每一句的施动者和动作能不能一眼找到？
- [ ] 每句话只有一个读法吗？
- [ ] 连词是在表达真实关系，还是在撑结构？
- [ ] 有没有为了显得完整凑出来的第三项？
- [ ] 句长是不是都差不多？（连着五句长度接近就拆一句或插一句短的）
- [ ] 段落长度是不是都差不多？
- [ ] 相邻句有没有重复同一个实词或同一个评价？
- [ ] 结尾是不是又总结、又升华了？
- [ ] 术语、引语、代码、路径有没有被顺手改掉？
- [ ] 有没有新增事实、数字、人名、经历？

有一条打不了勾就再改一遍。改完念一遍，念着别扭的地方通常还有问题。

## 输出格式

- 粘一段文字：给终稿，再用几行说明改了什么，别复述全文。
- 给文件：用 patch 改，改完给 diff 或改动小节，不静默覆盖。
- 会影响含义但拿不准的地方，单独列「需要你确认」，不替作者决定。

## 不做什么

- 不做作者身份鉴定，不说「这段一定是 AI 写的」。检测器对语言多样性低的写作者假阳率能到 61.22%（arXiv 2304.02819），低困惑度不等于 AI。
- 不用于规避检测、伪造身份或学术不端。这个 skill 只管把文字改好读、改出具体内容。
- 不把技术文档、公文、法律文本改成聊天口吻。正式语体不是 AI 痕迹。
- 不为「显得有人味」硬加第一人称、幽默或情绪。声口要来自作者，不来自模板。
